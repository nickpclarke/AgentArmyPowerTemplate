# 🧠 Data & Database Science Track

> [!abstract] North star
> Treat data as an evidence-backed product: measurable quality, explicit semantics, repeatable pipelines, and “trust you can test”.

**🎛 [[Obsidian Board]] · 🧭 [[Platform Atlas]] · 🏷️ [[Taxonomy]]**

## Start here

- [[Universal Data Adapter]] — connector registry + pipelines; ArcadeDB first, BigQuery next
- [[Data Products & Semantic Contracts]] — “what is the product?” and “what is the contract?”
- [[Schema Scout as Science]] — inspection as a scenario with measurable outputs
- [[Graph + Relational Together]] — multiple projections, one canonical model

## What we’re optimizing for

- **Change without drift** — schema changes are explicit and compatible, not surprising.
- **Measurable trust** — the default question is “what evidence proves this?”
- **Multi-model pragmatism** — graph for relationships, relational for analytics, object model for runtime.
