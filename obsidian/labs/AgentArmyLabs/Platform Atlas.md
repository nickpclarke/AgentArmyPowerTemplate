# 🧭 Platform Atlas (all layers)

> [!abstract] Purpose
> A platform that helps build platforms needs a shared mental model across **all layers**: UI, API, workers, data, infra — plus the **agentic loop** that ties them together with evidence.

**🎛 [[Obsidian Board]] · 🏠 [[Welcome]] · 🏷️ [[Taxonomy]]**

## 🧱 The layers (navigation)

- [[Layer — UI]] — human surfaces, forms, “projection UIs”
- [[Layer — API]] — contracts, gateways, stable interfaces for agents + humans
- [[Layer — Worker]] — long-running orchestration, queues, scenario execution
- [[Layer — Data]] — storage + semantics + evidence + projection pipelines
- [[Layer — Infra]] — identity, secrets, runtime, CI/CD, guardrails

## 🔁 The agentic-but-governed spine

- [[Agentic Loop Primitives]] — scenarios, policy, evidence, and the constraints that keep the system coherent
- [[Middle-Core]] — where “scenario + evidence + safety + contract” lives

## 🧪 Two threads that converge

- [[Model-Driven Platform]] — one model, many projections
- [[Universal Data Adapter]] — connector registry + pipelines (ArcadeDB → BigQuery next)

> [!tip] How to use this atlas
> Start at the layer you’re actively shaping, then follow links outward to primitives (scenario/policy/evidence) and inward to the canonical model.
