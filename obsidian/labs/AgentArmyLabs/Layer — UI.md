# Layer — UI

> [!abstract] Scope
> Human-facing surfaces: dashboards, forms, “projection viewers”, and review experiences for evidence and decisions.

**🎛 [[Obsidian Board]] · 🧭 [[Platform Atlas]]**

## Responsibilities

- Make scenarios understandable: “what will happen?” and “what happened?”
- Visualize evidence-packs and drift reports
- Provide safe affordances to propose model changes (via PRs / decision-records)

## Interfaces

- Consumes OpenAPI projections + typed contracts
- Navigates by stable IDs (business objects), not storage keys
