# PR Review Loop

Pull requests should be small, linked to issues, and validated before merge.

## Required PR body

Include one of:

- `Closes #N`
- `Fixes #N`
- `Resolves #N`

This allows board automation to move linked issues.

## Large PRs

The size label workflow marks PRs over 200 changed lines with `needs-deep-review`. Use a relevant specialist agent or human reviewer for deeper review.
