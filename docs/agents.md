# Starter Agents

AgentArmyPowerTemplate ships with a starter roster instead of the full specialist catalog. The goal is to cover common template work without overwhelming new repositories.

## Included clusters

- Product and planning: product manager, project manager, scrum master, business analyst, UX researcher.
- Engineering: API, frontend, backend, fullstack, JavaScript, TypeScript, Python.
- Delivery and security: DevOps, deployment, cloud, SRE, security engineering.
- Quality: code review, QA, security audit, accessibility, test automation.
- Documentation and workflow: documentation, README, dependency, and Git workflow specialists.
- Coordination: agent organizer, multi-agent coordination, workflow orchestration, HITL.
- Strategy: research, spikes, business architecture, capability planning, Wardley mapping.

Regenerate `docs/agents-glossary/index.md` after changing the roster.
