# Onboarding

Use this checklist when adopting the template.

- [ ] Repository placeholders replaced.
- [ ] License reviewed and accepted.
- [ ] GitHub Pages enabled.
- [ ] `PROJECT_NUMBER` variable configured.
- [ ] `PROJECT_TOKEN` secret configured.
- [ ] Issue templates reviewed for team language.
- [ ] PR template reviewed for required checks.
- [ ] CODEOWNERS replaced with real owners.
- [ ] Starter agent roster reviewed.
- [ ] Optional memory hooks reviewed before enablement.
- [ ] `Template sanity check` workflow passes.
