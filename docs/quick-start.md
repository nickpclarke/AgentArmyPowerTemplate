# Quick Start

1. Use this template to create a new repository.
2. Replace placeholder values in `mkdocs.yml`, `.github/CODEOWNERS`, and setup docs.
3. Create a GitHub Projects v2 board and set `PROJECT_NUMBER`.
4. Add `PROJECT_TOKEN` as a repository secret.
5. Open a test issue with the `copilot-task` label.
6. Run `Template sanity check` from GitHub Actions.
7. Build docs locally with `python -m mkdocs build`.

After setup, use `copilot-task` for bounded automation and `ai-agent-task` for larger specialist-agent work.
