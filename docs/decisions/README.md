# Architecture Decision Records

Create new ADRs as `ARC-ADR-DRAFT-<slug>.md`. Do not hand-pick numbers.

## Template

| Field | Value |
|---|---|
| Status | Proposed |
| Date | YYYY-MM-DD |
| Owner | Team or role |
| Related | Issues, PRs, docs |

---

# ARC-ADR-DRAFT: Title

## Context

What decision is needed and why now?

## Decision

What option was chosen?

## Consequences

What changes, risks, and follow-up work result?

## Validation

How will the team confirm the decision is working?
