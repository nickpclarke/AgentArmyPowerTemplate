# Routing Matrix

| Signal | Route | Label |
|---|---|---|
| Single-file docs/config update | GitHub Copilot | `copilot-task` |
| Small workflow tweak | GitHub Copilot or DevOps specialist | `copilot-task` |
| Agent roster or routing design | Documentation + agent organizer | `ai-agent-task` |
| Security-sensitive workflow | Security engineer + security auditor | `ai-agent-task` |
| Architecture or governance decision | HITL decision artifact | `awaiting-human` |
| Large PR | Deep review | `needs-deep-review` |

When uncertain, start with `ai-agent-task` and document the decision in the issue.
