# Issue Conventions

## Recommended labels

- Type: `bug`, `feature`, `docs`, `spike`, `enabler`, `decision`.
- Size: `XS`, `S`, `M`, `L`, `XL`.
- Routing: `copilot-task`, `ai-agent-task`.
- State: `blocked-by`, `awaiting-human`.
- Priority: `P0`, `P1`, `P2`, `P3`.

## Issue body

A good issue includes the goal, acceptance criteria, relevant files, constraints, and validation expectations.
