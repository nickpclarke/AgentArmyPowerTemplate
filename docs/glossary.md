# Glossary

**ADR** — Architecture Decision Record; a lightweight document for durable decisions.

**AI** — Artificial Intelligence; in this template, mostly agent-assisted development workflows.

**API** — Application Programming Interface; a defined contract for software integration.

**ARC** — Architecture; the prefix used for architecture decision record identifiers in this template.

**CI** — Continuous Integration; automated checks run by GitHub Actions.

**CODEOWNERS** — GitHub ownership file that requests reviews from maintainers or teams for matching paths.

**DD** — Day; the two-digit day placeholder used in date examples.

**DRAFT** — A temporary state for unnumbered architecture decision records before merge-time numbering.

**HITL** — Human-in-the-loop; a decision point that requires human judgment.

**MM** — Month; the two-digit month placeholder used in date examples.

**MkDocs** — Static documentation generator used for the template site.

**OWNER** — Placeholder for the GitHub user or organization that owns a derived repository.

**P0** — Priority zero; the most urgent priority level.

**P1** — Priority one; high priority after P0.

**P2** — Priority two; medium priority.

**P3** — Priority three; lower priority.

**PI** — Planning Increment; a medium-range delivery planning horizon.

**PR** — Pull Request; the review and merge unit for repository changes.

**QA** — Quality Assurance; practices and checks that help verify fitness for use.

**README** — The repository landing document that explains purpose, setup, and usage.

**SAFe** — Scaled Agile Framework; used here in a lightweight form for issue hierarchy and planning language.

**SRE** — Site Reliability Engineering; reliability-focused engineering practices for operating systems.

**TOML** — Tom's Obvious Minimal Language; a configuration file format used for generated Codex profiles.

**UX** — User Experience; how people perceive and interact with a product or workflow.

**XL** — Extra large; the largest issue or work-item size in the template's sizing scale.

**XS** — Extra small; the smallest issue or work-item size in the template's sizing scale.

**YAML** — YAML Ain't Markup Language; a structured configuration format used by GitHub Actions and templates.

**YYYY** — Year; the four-digit year placeholder used in date examples.
